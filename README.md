# 📚 Online Book Resale and Purchase System

A web-based application that allows users to buy and sell used books online. The system provides separate functionalities for users, sellers, and administrators.

## 🎯 Project Objective

The main objective of this project is to provide a simple and user-friendly platform where users can list their used books for sale and purchase books from other users.

## ✨ Features

### 👤 User
- User registration and login
- Browse available books
- Search and filter books
- View book details
- Add books to cart
- Place orders
- Manage profile
- Wishlist
- Messaging

### 👨‍💼 Admin
- Admin login
- Manage users
- Manage books
- Manage categories
- Manage orders
- Manage payments
- View reports
- Manage feedback

### 📖 Seller
- Add books
- Edit book details
- Upload book images
- Manage listed books
- Manage seller orders

## 🛠️ Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap
- XAMPP

## 🗄️ Database

MySQL is used as the database management system.

**Database Name:**
`online_book_resale`

The SQL database file is available inside the `database/` folder.

## ⚙️ Installation

1. Install [XAMPP](https://www.apachefriends.org/).
2. Start **Apache** and **MySQL**.
3. Clone or download this repository.
